以前作った[互いに接している国を言っていくゲーム](https://coiluck.github.io/CountryChain)について、僕は以下のような指摘をした。

> ロシア→フィンランド→スウェーデン→ノルウェーで行き止まりだから、ロシアを言った方が負けてしまう。ところで中国を相手が言った場合、自分が次にモンゴルと言えば相手はその次に必ずロシアを言うことになるから中国を相手に言わせたら勝ち確だ。 

モンゴルに接しているのはロシアと中国だけで、中国はもう言われているので、相手はロシアを言うしかない。相手の自由な選択を許さずに詰み状態まで持っていくことができるのだ。

これは僕が実際にプレイするなかで見つけたコンボだった。

このコンボは相手がノルウェーとスウェーデンのどちらを選択しても勝てるという高度なギミックになっているし、僕はこれ以外の長いコンボを見つけられていなかった。そのため実のところ、僕は自分が見つけたものが最長だろうと高をくくっていた。……本当だろうか。

というわけでこれを機械的に探索してよりテンションの上がるコンボを見つけてみる。ちなみにここで言うテンションが上がるとは、必殺コンボが長いことを言っている。

## 問題の整理
ゲームの状態は今言われた国（この国に接している国の中から選ぶ）と既出でもう使えない国の2つだけだ。正確にはプレイヤーが二連続間違えたら負け、のためのカウントもあるのだが、今回の探索に関係はない。つまり、

先手：言える国のうち、どれか1つで勝ち確ならいい<br>
後手：先手が言える国の全部に詰まされないと言えないといけない

ということが言える。ここで、後者がやばい。もうあれだ、電撃文庫の本が芥川賞をとったくらいやばい。うわ、だいぶやばいな。

何が言いたいのかというとこのゲームは勝ちか負けしかないため、詰まされないことを言うには勝つ方法があることを言わないといけないのだ。じゃあこれが互いにやりとりを30回した後に勝てたとしたら？　そこまで本当に探索するのか？

というわけで仕方がないからあらかじめ宣言する定数の回数分しか探索しない。そこまで探索して詰ませられないならば、それは無理だったということにする。そのため今から話す探索はN手で詰ませられるのかどうかを判定してるだけに過ぎない。

## 寄り道
調べたらこの問題には Undirected Vertex Geography という名前がついていて、「最大マッチングを使えば勝敗のみが多項式時間でわかる」という定理まであるらしい。よくよく読んでみたのだが、何度読んでも目が滑ってしまう。微塵も理解できずに撤退した。

## 実装
僕は再帰的な処理を書くのが苦手だが一生懸命書いてみた。貴重な、人間の書いた温かみのあるコードだぞ、オラッ！

```typescript
type Strategy = { play: string; replies: { reply: string; next: Strategy }[] };

function searchCombo(countries: CountryMap, current: string, used: Set<string>, depth: number): Strategy | null {
  if (depth === 0) return null;

  // 自分の番
  for (const myMove of getLegalMoves(countries, current, used)) {
    used.add(myMove);

    const replies: Strategy['replies'] = [];
    let allWin = true;

    // 相手の番：全部の手に勝てないといけない
    for (const eneMove of getLegalMoves(countries, myMove, used)) {
      used.add(eneMove);
      const next = searchCombo(countries, eneMove, used, depth - 1);
      used.delete(eneMove);

      if (next === null) {   // 1つでも勝てない返しがあったら
        allWin = false;      // この myMove はダメ
        break;
      }
      replies.push({ reply: eneMove, next });
    }

    used.delete(myMove);

    if (allWin) return { play: myMove, replies };
  }

  return null; // どの手を試しても自分は詰ませられない
}
```

この `used` に `current` だけを入れた状態で、すべての国を `current` として回していく。

幅が大きすぎる。これ人間が「最終的に30個近くに分岐するけど全部勝てるんですよね～」とかいってたら賢すぎて驚いちゃうと思う。

ログを見てみるとほぼ以下の二つに帰結していた。

1. ヨーロッパに飛んでデンマークを言う
2. ロシアに飛んでスカンジナビア半島で詰ませる

今回はフランス領ギアナからヨーロッパに飛んでいたので手前のデンマークの登場が多いが、2のパターンも随分とあった。僕が見つけたのは人間が扱いやすい分岐が少ない最後だけで、ロシアからもっといろいろなコンボが生まれていた。

相手の返しはすべて調べているので、これが必勝コンボであることは間違いない。ただし自分の手は最初に勝てるとわかったものを選んでいるだけなので、別の手を選べば、もっと長いコンボやもっと短くわかりやすいコンボがあるかもしれない。
